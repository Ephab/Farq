## Findings

### C1 — Start-the-chat button text invisible (black on black)
- **Layer**: Visual **Severity**: Critical **Surface**: onboarding Chat, 1440×900
- **Persona**: new undergrad onboarding
- **Reproduce**: 1. Fresh sign-in → Basics (fill all) → Continue. 2. Review suggestions → Continue. 3. Observe center card button.
- **Observed**: Solid black rectangle, no readable label. Computed style: `color rgb(9,9,11)` on `background rgb(9,9,11)` (1:1). Screenshot `A11-chat.png`. DOM label is `Start the chat`.
- **Expected**: White `Start the chat` label like `Generate my roadmap` (rgb 250 on rgb 9).
- **Evidence**: `A11-chat.png`; computed-style dump (Start the chat: `rgb(9,9,11)/rgb(9,9,11)` vs Generate: `rgb(250,250,250)/rgb(9,9,11)`).
- **Suspected location**: `src/components/onboarding/OnboardingChat.tsx` (button `mt-5 h-9 ... bg-primary text-primary-foreground` inside `.fq` scope overriding `--primary-foreground`).
- **Smallest patch**: Scope the `.fq` CSS var override to exclude primary buttons, or set the button to `text-white` explicitly; verify computed color is `rgb(250,250,250)`.
