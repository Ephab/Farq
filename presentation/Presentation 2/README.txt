Waypoint HTML presentation

Open Waypoint-Presentation.html in Chrome or Edge. It is self-contained and works offline.

Space / right arrow / click: next section
Left arrow: previous section
F: full screen
O: section roadmap
N: Arabic speaker notes (visible on the same screen)
Home: return to the opening
Swipe: next / previous on touch screens

15 stops: opening, four student difficulties, section overview, eight product sections, closing. Suggested section times total five minutes, including transitions. Transitions wait for your click.

The logo, partner marks and six product screenshots come from the supplied Waypoint-pitch.pptx. They are reference views, not a connection to the running application. Content is grounded in the project README and docs/problem-solution.md.

Editable source: index.html, styles.css, app.js, assets/.
After editing, run package.py with Python to rebuild the standalone file.

Project application code was not modified.
