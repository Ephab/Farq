Waypoint · cinematic pitch (Arabic, ~5 min)

Open index.html in Chrome or Edge (works offline: fonts, GSAP, images and videos are local).
Press F for fullscreen.

Next   : Right / Down / PageDown / Space / Enter / left click (presenter clickers work)
Back   : Left / Up / PageUp / Backspace / right click
Home / End : first / last beat
N      : speaker notes with beat counter and elapsed timer

23 beats: title → 4 problems along a grey thread → convergence → road overview →
6 cards (each: zoom + expand, then a second press plays its "you decide" build) →
graduation → the whole journey as one line → closing.
